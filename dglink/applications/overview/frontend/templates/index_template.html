DGLink: Semantic interoperability for biomedical data portals

DGLink brings semantic interoperability to data portals through automated metadata extraction and knowledge-graph construction. It links data within a portal and maps it to external knowledge, enabling knowledge-driven data interpretation and cross-portal discovery.

This page is the hub for the DGLink tool suite. Explore the graph statistics below, then jump into the Chat Assistant{% if show_sequence %}, Query Builder, or Sequence Search{% else %} or Query Builder{% endif %} — or run a natural-language query right here.

Interoperability

Inside the merge

Every node and edge records the portal(s) it came from. When DGLink recognizes that an entity seen in different portals is the same real-world thing, it collapses them into one node whose portal list keeps every origin. Those shared nodes are the bridges that make cross-portal questions answerable.

Application

MCP Chat Assistant

The Chat Assistant connects a large language model directly to the graph database using the Model Context Protocol (MCP). Ask a question in plain English; the model uses MCP tools to write and run Cypher against Neo4j, then answers from the results — with responses streaming in as they are generated.

  • MCP integration: direct, tool-based access to Neo4j via the mcp-neo4j-cypher server.
  • Dual model support: switch between Anthropic (Claude) and OpenAI (GPT).
  • Real-time streaming with full markdown and table rendering.
  • Cross-portal reasoning: a single question can span GDC, GC, and PDC data.
